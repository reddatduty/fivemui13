# fivemui13

Standalone browser UI prototype for a GTA V / FiveM vehicle tuning system.

## Test it

Just open `index.html` in your browser.

No FiveM resource files, Lua, server, framework, build step, or backend are required.

The UI contains demo data for:
- Cash, Bank, Diamante and Lei balances
- Paint finishes and color selection
- Engine stages, including Stage 4 Turbo
- Suspension
- Armor
- Body parts
- Liveries
- Neon
- Headlights
- Tire smoke
- Wheels
- 30 engine sound presets
- Preview states
- Build/cart flow
- Multi-currency checkout

Files:
- `index.html`
- `style.css`
- `app.js`

Everything is front-end only and can be opened locally for visual testing.
